# SEO Phase 2 - Keyword Map (PL)

## Scope

Phase 2 focuses on on-page SEO for the highest-intent marketing pages:

- home (`/`)
- `/dla-wspolnot`
- `/dla-wykonawcow`
- `/kategorie-uslug`
- `/faq`
- `/kontakt`
- `/o-nas`
- `/aktualnosci`

## Primary intent buckets

### 1) Demand from property managers and housing communities

- platforma dla zarządców nieruchomości
- konkurs ofert dla wspólnoty mieszkaniowej
- przetargi dla spółdzielni mieszkaniowych
- wybór wykonawcy remontu bloku

**Mapped pages:** `/`, `/dla-wspolnot`, `/zarzadcy`, `/pomoc-dla-zarzadcow`

### 2) Demand from contractors and service firms

- zlecenia dla firm budowlanych
- zlecenia B2B dla wykonawców
- przetargi remontowe dla firm
- konkursy ofert dla wykonawców

**Mapped pages:** `/`, `/dla-wykonawcow`, `/wykonawcy`, `/pomoc-dla-wykonawcow`

### 3) Informational and trust content

- FAQ vestiqo
- pytania i odpowiedzi dla zarządców
- kontakt vestiqo
- platforma przetargowa nieruchomości
- aktualności nieruchomości

**Mapped pages:** `/faq`, `/kontakt`, `/o-nas`, `/aktualnosci`

## On-page implementation summary

- Added route-level keyword metadata for major marketing pages.
- Improved intro copy with target phrases aligned to search intent.
- Added FAQPage schema markup on `/faq`.
- Added internal-link blocks on priority landing pages to strengthen crawl paths.

## Next phase candidates

- Add long-tail article content with publish dates/authors in `/aktualnosci`.
- Add case-study landing pages for top service categories and cities.
- Track CTR and query coverage in Search Console, then iterate titles/meta descriptions.
